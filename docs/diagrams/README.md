# Schémas d'architecture

Fichiers éditables au format **draw.io / diagrams.net**. Pour les ouvrir : [app.diagrams.net](https://app.diagrams.net) (Open Existing Diagram) ou l'extension draw.io dans VS Code. Export PNG/SVG pour le rapport et les diapositives.

| Fichier | Contenu |
|---|---|
| [`01-co-atc-nominal.drawio`](01-co-atc-nominal.drawio) | Flux normal de co-atc, avant toute attaque |
| [`02-architecture-proxy-attaque.drawio`](02-architecture-proxy-attaque.drawio) | Banc d'essai : proxy d'attaque Python interposé (architecture principale) |
| [`03-transformation-clonage.drawio`](03-transformation-clonage.drawio) | Attaque V1 : un avion réel → un réel + N leurres |

D'autres schémas (séquence Mermaid, etc.) sont intégrés directement dans [`../architecture.md`](../architecture.md). On ajoutera ici tout nouveau schéma structurant au fur et à mesure.
